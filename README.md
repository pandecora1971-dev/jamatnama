# জামায়াতনামা · JAMATNAMA

জনস্বার্থ ওয়েবসাইটের দৃশ্যমান নকশা ও ফিচার অনুসরণ করে তৈরি বাংলা Next.js অ্যাপ। হলুদ অ্যাকসেন্টের পরিবর্তে `#FF7873`। রেফারেন্স: https://jonoshartho.com/

> **প্রোডাকশন:** এই অ্যাপ এখন Vercel + Supabase PostgreSQL + private Cloudflare R2-এর জন্য তৈরি। ধাপগুলো [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md) এবং পরীক্ষার ফলাফল [docs/VERIFICATION-RESULTS.md](docs/VERIFICATION-RESULTS.md)-এ আছে। নিচে SQLite, BLOB, SSE, ৩টি ফাইল বা ৫ MB সংক্রান্ত উল্লেখ পুরোনো আচরণের বিবরণ।

## চালু করুন

Node.js 24 বা পরবর্তী সংস্করণ প্রয়োজন।

```sh
npm ci
npm run admin:setup
npm run dev:stack   # আলাদা টার্মিনালে; দেখানো মানগুলো .env.local-এ যোগ করুন
npm run dev
```

সাইট: http://127.0.0.1:3000/  
অ্যাডমিন: http://127.0.0.1:3000/admin

`npm run admin:setup` একটি শক্তিশালী পাসওয়ার্ড ও সেশন সিক্রেট তৈরি করে। পাসওয়ার্ড শুধু স্থানীয় `.admin-access.txt` ফাইলে থাকে; `.env.local`-এ পাসওয়ার্ডের scrypt হ্যাশ থাকে। দুটি ফাইলই Git ও Docker থেকে বাদ দেওয়া। কমান্ডটি আবার চালালে পাসওয়ার্ড বদলাবে ও পুরোনো সেশন বাতিল হবে। সেটআপের পরে সার্ভার পুনরায় চালু করুন।

## কাজ করে যেভাবে

- সাইটের উপকারিতা, রিপোর্টের প্রস্তুতি ও কাল্পনিক লেখার নমুনা, জমা থেকে প্রকাশের চার ধাপ, গোপনীয়তা এবং ব্যবহারকারীর প্রত্যাশা বোঝাতে আলাদা বাংলা সেকশন আছে। নতুন পেন্সিল আঁকাগুলো স্ক্রলের সঙ্গে ফুটে ওঠে; প্রস্তুতি, ট্র্যাকিং ও গোপনীয়তার বোতাম আসল ফর্ম/ডায়ালগ খোলে।
- হিরোর ডান পাশে হালকা পেন্সিল আঁকার অ্যানিমেশন: কথার বুদবুদ, খোলা খাতা ও লিখতে থাকা কলম। মোবাইলে আঁকাটি নিচে ছোট আকারে থাকে; reduced-motion সেটিংয়ে স্থির হয়।
- নতুন বাংলা হেডলাইন: “আপনার কণ্ঠেই জবাবদিহির শুরু হোক।” অ্যাকসেন্ট রং `#FF7873`।
- রিপোর্ট ফর্মে এলাকা নির্বাচনের সঙ্গে বাংলাদেশ মানচিত্রে বিভাগ/জেলা হাইলাইট, উপজেলা সীমানা এবং চলমান পিন আপডেট হয়। যেসব থানার নির্ভরযোগ্য সীমানা নেই, সেখানে জেলার অবস্থান ও পরিষ্কার ব্যাখ্যা দেখানো হয়। মোবাইলে মানচিত্রটি ফর্মের ওপর ছোট আকারে দৃশ্যমান থাকে।
- হেডলাইন, স্ক্রল, কার্ড, ডায়ালগ ও সফল রিপোর্টের জন্য হালকা অ্যানিমেশন আছে। `prefers-reduced-motion` চালু থাকলে চলমান অ্যানিমেশন বন্ধ থাকে।

- বড় মানচিত্রের পাশে ফর্ম স্ক্রল হয়; নিচের জমা দেওয়ার বাটন সবসময় দৃশ্যমান থাকে।
- অভিযুক্তের নাম ও প্রাসঙ্গিক তথ্যের আলাদা অংশ আছে; সর্বোচ্চ ১০ জন যোগ বা সরানো যায়। নাম অজানা হলেও সংশ্লিষ্ট তথ্য দেওয়া যায়। এই তথ্য শুধু লগইন করা পর্যালোচক দেখতে পারেন; সাধারণ তালিকা ও API-তে আলাদা অংশটি প্রকাশিত হয় না।
- রিপোর্টকারীর নাম, ফোন, ইমেইল বা অ্যাকাউন্ট ছাড়াই অভিযোগ জমা হয়। রিপোর্টকারীর IP অ্যাপের ডেটাবেসে রাখা হয় না।
- ২০টি ক্যাটাগরি, শর্ত অনুযায়ী অতিরিক্ত তথ্য, ৮ বিভাগ, ৬৪ জেলা এবং উপজেলা/মহানগর থানা নির্বাচন।
- সর্বোচ্চ ৩টি প্রমাণ: JPG, PNG, WebP, PDF, MP3 বা WAV; প্রতিটি সর্বোচ্চ ৫ MB। ছবির মেটাডেটা বাদ দিয়ে WebP তৈরি হয়। PDF ব্যক্তিগত সংযুক্তি হিসেবে রাখা হয়; PDF-এর মেটাডেটা স্বয়ংক্রিয়ভাবে মুছে ফেলার দাবি করা হয় না।
- অভিযোগ ও প্রমাণ SQLite-এ স্থায়ীভাবে সংরক্ষিত হয়। প্রমাণ সাধারণ দর্শক দেখতে পারেন না। লগইন করা পর্যালোচক ফাইল ডাউনলোড করতে পারেন। মূল ফাইলের নাম সংরক্ষণ করা হয় না।
- নতুন অভিযোগ `pending` অবস্থায় থাকে। অ্যাডমিন ব্যক্তিগত তথ্য সরিয়ে, প্রমাণ যাচাই করে অনুমোদন/প্রত্যাখ্যান/পুনরায় পর্যালোচনায় পাঠাতে পারেন।
- গোপন ট্র্যাকিং কোড দিয়ে রিপোর্টকারী অবস্থা ও পর্যালোচকের মন্তব্য দেখতে পারেন। শুধু কোডের হ্যাশ সংরক্ষিত হয়। কোড হারালে উদ্ধার করা যায় না।
- প্রকাশের পরে তালিকা, গণনা, মানচিত্র ও পরিসংখ্যান Server-Sent Events-এর মাধ্যমে স্বয়ংক্রিয়ভাবে আপডেট হয়। সংযোগ বিচ্ছিন্ন হলে পুনঃসংযোগ ও ৩০ সেকেন্ড অন্তর বিকল্প আপডেট আছে।
- কীওয়ার্ড, ক্যাটাগরি, বিভাগ, জেলা, উপজেলা এবং তারিখ দিয়ে ফিল্টার; বিস্তারিত ডায়ালগ, রিপোর্টের লিংক কপি, আরও রিপোর্ট দেখা।
- মানচিত্রে ৬৪ জেলার সীমানা, সংখ্যা, এলাকা/ক্যাটাগরি/তারিখের ফিল্টার, জুম এবং কীবোর্ড দিয়ে জেলা নির্বাচন। কোনো বাহ্যিক ম্যাপ ট্র্যাকার নেই।
- ব্রাউজার কুকির সাহায্যে একটি রিপোর্টে একবার সমর্থন গণনা হয়। এটি ব্যক্তি-ভিত্তিক যাচাই নয়; কুকি মুছলে বা অন্য ব্রাউজার ব্যবহার করলে পুনরায় সমর্থন সম্ভব। সমর্থন অভিযোগের সত্যতা প্রমাণ করে না।

বাস্তব প্রকাশিত রিপোর্ট না থাকলে স্পষ্ট “নমুনা” চিহ্নসহ ৮টি কাল্পনিক রিপোর্ট দেখায়। “বাস্তব রিপোর্ট দেখুন” দিয়ে খালি বাস্তব তালিকা দেখা যায়। নমুনা ডেটা ডেটাবেসে লেখা হয় না। কোনো বাস্তব ব্যক্তির বিরুদ্ধে অভিযোগ আমদানি করা হয়নি।

## প্রোডাকশন

```sh
npm run build
npm start
```

এটি আসল Next.js App Router অ্যাপ; static export নয়। একটি স্থায়ী Node.js সার্ভার ও লেখার উপযোগী ডিস্ক প্রয়োজন। SQLite ডেটাবেস ও প্রমাণ একই `DATA_DIR`-এ থাকে (ডিফল্ট `./data`)। সেই পুরো ডিরেক্টরির ব্যাকআপ নিন; চলমান ডেটাবেসের জন্য SQLite backup API বা থামানো সার্ভারের সামঞ্জস্যপূর্ণ কপি ব্যবহার করুন।

Docker প্রস্তুত:

```sh
docker build -t jamatnama .
docker run -p 3000:3000 --env-file .env.local -v jamatnama-data:/app/data jamatnama
```

প্রকাশ্য পরিবেশে HTTPS চালু করে `COOKIE_SECURE=true` দিন। স্থানীয় HTTP-তে `false` রাখুন। রিভার্স প্রক্সি Host হেডার অক্ষত রাখবে; সর্বোচ্চ রিকোয়েস্ট আকার ১৬ MB এবং streaming/SSE buffering বন্ধ রাখবে। একটি SQLite volume-সহ একটিমাত্র app replica চালান; একাধিক server/replica বা ephemeral serverless filesystem-এর জন্য আগে shared database ও private object storage-এ migration প্রয়োজন।

অ্যাপ নিজে IP বা browser fingerprint সংগ্রহ করে না; হোস্টিং, রিভার্স প্রক্সি, CDN ও error-monitoring-এর access log নীতিও গোপনীয়তার প্রয়োজন অনুযায়ী কনফিগার করতে হবে। লেখার মধ্যে বা PDF-এর মধ্যে পরিচয় থাকলে অ্যাপ নিজে তা নির্ভুলভাবে শনাক্ত করতে পারে না—প্রকাশের আগে পর্যালোচনা আবশ্যক। ফাইল type/size validation, image decode ও re-encoding আছে; পূর্ণ malware scanning যুক্ত করা হয়নি।

বট প্রতিরোধে একবার ব্যবহারযোগ্য মেয়াদযুক্ত challenge, honeypot, পুনরাবৃত্তি পরীক্ষা ও সার্ভার-ব্যাপী rate limit আছে। জনসাধারণের বড় ট্রাফিকের আগে হোস্টের abuse controls উপযোগী করে কনফিগার করুন।

এখনও কোনো পাবলিক সার্ভারে প্রকাশ করা হয়নি। Sites-এর Worker runtime-এ Node SQLite-সহ এই Next.js backend সরাসরি চলে না; Next.js ও স্থায়ী storage সমর্থনকারী হোস্টে এই সোর্স বা Docker image deploy করুন।

## পরীক্ষা

```sh
npm test
npm run typecheck
npm run build
```

ভ্যালিডেশন, পরিচয় ফিল্ড বাদ দেওয়া, ভুল এলাকা/তারিখ প্রত্যাখ্যান, request body limit, স্বাক্ষর ও পাসওয়ার্ড যাচাই এবং cross-origin protection-এর unit test আছে। স্থানীয় ব্রাউজার ও API-তে report → private evidence → moderation → live publication → tracking → support → unpublish প্রবাহ যাচাই করা হয়েছে।

চালু স্থানীয় সার্ভারে API প্রবাহ পুনরায় পরীক্ষার জন্য `node scripts/verify-flow.mjs` চালানো যায়; এটি স্থানীয় `.admin-access.txt` থেকে পরীক্ষার জন্য লগইন করে। শুধু নিজের স্থানীয় development database-এ ব্যবহার করুন। এটি স্পষ্টভাবে কাল্পনিক পরীক্ষার রিপোর্ট তৈরি করে এবং তার নিজস্ব রিপোর্ট মুছে ফেলে।

## রেফারেন্স ও ডেটা

দৃশ্যমান নকশার রেফারেন্স: জনস্বার্থ। WordPress-এর সার্ভার, গোপন অ্যাডমিন ব্যবস্থা বা moderation logic পাওয়া যায়নি; সেগুলো এখানে নতুন করে তৈরি করা হয়েছে। অভিযোগ স্বয়ংক্রিয়ভাবে সত্য/“Verified” হিসেবে চিহ্নিত হয় না।

লোকেশন ও মানচিত্রের উৎস: রেফারেন্সের প্রকাশ্য `bangladesh-locations.json` এবং `bangladesh-upazilas.geojson`। সীমানা হালকা SVG paths-এ রূপান্তর করা হয়েছে। Map data © সংশ্লিষ্ট contributors, ODbL: https://opendatacommons.org/licenses/odbl/1-0/ । সীমানা নির্দেশক; আইনগত সীমানা নির্ধারণের উপকরণ নয়।

### হিরোর পেন্সিল অ্যানিমেশন

হিরোতে ১২টি প্রতীকী SVG চিত্র ৭.২ সেকেন্ড পরপর আঁকা হয়ে পাল্টায় এবং শেষ চিত্রের পর প্রথমটিতে ফেরে। থামানো ও পরের চিত্র দেখার কন্ট্রোল আছে। পেজ/চিত্র দৃশ্যমান না থাকলে অ্যানিমেশন বিরতি নেয়; reduced-motion পছন্দে স্বয়ংক্রিয় চলাচল বন্ধ থাকে।

### অডিও, সংবাদসূত্র ও নতুন ক্যাটাগরি

প্রমাণ হিসেবে JPG/PNG/WebP/PDF-এর সঙ্গে MP3 ও WAV গ্রহণ করা হয় (সব মিলিয়ে সর্বোচ্চ ৩টি ফাইল, প্রতিটি ৫ MB)। অডিওর কাঠামো যাচাই করা হয়; কণ্ঠ বা মেটাডেটা মুছে ফেলা হয় না। ঐচ্ছিক সর্বোচ্চ ৫টি HTTP(S) সংবাদলিংক আলাদা টেবিলে সংরক্ষিত হয়; সার্ভার লিংকগুলো নিজে fetch করে না। ফাইল ও লিংক শুধু অ্যাডমিন দেখতে পারেন। পুরোনো চুরি/ডাকাতির রিপোর্ট মূল তথ্য অক্ষত রেখে সম্মিলিত ক্যাটাগরিতে প্রদর্শিত হয়।

### নিরাপত্তা ও production setup

Brute-force throttling, একবার ব্যবহারযোগ্য TOTP, বাতিলযোগ্য session, bounded request processing, Turnstile integration এবং private moderation hint যুক্ত হয়েছে। Live চালানোর আগে [নিরাপত্তা ও deployment নির্দেশনা](docs/SECURITY-DEPLOYMENT.md) অনুসরণ করুন। production-এ required origin, HTTPS cookie, 2FA ও Turnstile config না থাকলে sensitive action বন্ধ থাকে। কোনো বাইরের AI-এ রিপোর্ট পাঠানো হয় না।
